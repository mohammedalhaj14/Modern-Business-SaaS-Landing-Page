# Nexus | Modern SaaS Landing Page

Nexus is a high-conversion, professional landing page designed for SaaS (Software as a Service) platforms. It features a clean, responsive layout with integrated WhatsApp lead generation, a detailed features grid, and a high-contrast pricing table.

## 🚀 Live Demo
**View the live site here:** [https://mohammedalhaj14.github.io/Modern-Business-SaaS-Landing-Page/](https://mohammedalhaj14.github.io/Modern-Business-SaaS-Landing-Page/)

---

## ✨ Features

* **Responsive Design:** Fully optimized for Desktop, Tablet, and Mobile devices.
* **WhatsApp Integration:** A custom contact form and floating button that sends user inquiries directly to your WhatsApp number (+961 76 241 76).
* **High-Contrast UI:** Carefully selected color palettes to ensure maximum readability and professional appeal.
* **Single Page Navigation:** Smooth scrolling links for Features, Pricing, and Contact sections.
* **Modern Aesthetics:** Built with the Inter Google Font and clean CSS grid/flexbox layouts.

---

## 🛠️ Tech Stack

* **HTML5:** Semantic structure for SEO and accessibility.
* **CSS3:** Custom styling with CSS variables, transitions, and responsive media queries.
* **JavaScript (Vanilla):** Logic for form data extraction and WhatsApp API string encoding.

---

## 📂 Project Structure

```text
├── index.html       # Main landing page structure
├── style.css        # Professional styling and layout
└── script.js       # WhatsApp integration and logic

```

---

## ⚙️ How to Customize

1. **Change the WhatsApp Number:**
In `script.js`, locate the `myNumber` variable and change it to your own international format (no `+` or spaces).
2. **Edit Pricing:**
Open `index.html` and scroll to the `#pricing` section to update the plans and costs.
3. **Update Brand Name:**
Search for "Nexus" in `index.html` and replace it with your company name.

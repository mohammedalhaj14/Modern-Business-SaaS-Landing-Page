# 🚀 Nexus | Modern Business SaaS Landing Page

Nexus is a professional, high-performance landing page designed for SaaS platforms and modern businesses. This project focuses on high conversion rates, clean UI/UX, and a seamless lead generation flow via WhatsApp.

## ✨ Key Features

* **Optimized UI/UX:** High-contrast buttons and a clean layout ensure a professional appearance and ease of use.
* **WhatsApp Lead Delivery:** A custom-built contact form that captures user data and formats it into a direct WhatsApp message to the owner (+961 76 241 76).
* **Floating Support Button:** A persistent WhatsApp bubble in the corner to encourage instant communication.
* **Integrated Sections:** Includes a Hero section, Features showcase, and a specialized Pricing table.
* **Mobile Responsive:** Fully fluid layout that adapts perfectly to smartphones, tablets, and desktops.

## 🛠️ Built With

* **HTML5** - Semantic structure for better SEO.

* **JavaScript (ES6)** - Handles dynamic message encoding and WhatsApp API redirection.

---

## 🚀 How It Works (WhatsApp Integration)

The project uses a specialized script to handle communication:
1.  **Data Capture:** The form gathers the user's Name, Email, and Message.
2.  **Encoding:** JavaScript uses `encodeURIComponent` to format the text into a WhatsApp-friendly URL string.
3.  **Redirection:** The site triggers `https://wa.me/` to open the WhatsApp app (or web) with the message pre-filled.
